# YOUR NAME® — Portfolio Template

動画・SNS ビジュアル・Web デザインを手がけるクリエイターのための、個人ポートフォリオ・テンプレートです。
コードが書けなくても、**2 つのファイルを書き換えるだけ**で自分のサイトになります。

| ファイル | 役割 |
|---|---|
| `src/site.config.ts` | 名前・配色・ナビ・各セクションの ON/OFF など「設定」 |
| `src/data/site.ts` | 作品・プロフィール・サービスなど「中身」 |
| `src/i18n/ja.ts` / `src/i18n/en.ts` | ボタンやラベルの文言（日英） |

---

## 1. 3 分で始める（site.config.ts を触る）

`src/site.config.ts` を開いて、上から順に 3 か所だけ直せば最小構成が完成します。

1. **brand（ブランド）**
   ```ts
   name: 'YOUR NAME',        // ← 自分の名前に
   tagline: ['VISUAL', 'DESIGNER'],  // ← トップの大きな文字（2 行）
   email: 'hello@example.com',       // ← 自分のメールアドレスに
   location: '都市名, 国名',          // ← 例: 'Tokyo, Japan'
   available: true,           // 仕事の受付状況。false にすると「停止中」表示に一括切替
   ```
2. **theme（配色）**：`preset: 'acid'` を `'editorial'` か `'mono'` に変えるだけで全ページの色が変わります（詳しくは第 3 章）。
3. **保存するだけ**。開発サーバー（`coze dev`）を動かしていれば、ブラウザに即反映されます。

## 2. 作品とカバー画像を差し替える

作品はすべて `src/data/site.ts` の `projects` 配列に入っています。

1. 既存のエントリを 1 つコピーし、配列の末尾に貼り付ける。
2. `id`（URL になる英小文字）・`cat`（`youtube` / `instagram` / `tiktok` / `web` のどれか）・`year`・`title`・`platformUrl`（公開先の URL）・`paragraphs`（詳細文）を書き換える。
3. ファイル末尾にある**コメントアウトされた記入例**が雛形です。そのまま写して書き換えれば OK。
4. 件数の表示（`(08)` など）や一覧の並びは**自動で更新**されます。数える必要はありません。

**カバー画像について**：
初期状態では、カバーは seed（`coverSeed`）から自動生成されるプレースホルダー画像です。`cat` に合ったモチーフ（再生ボタン・スマホ枠など）が自動で入ります。
自分の画像に差し替える場合は、画像を `public/images/` に入れ、`site.ts` 内の `img()` 関数の戻り値をそのパスに書き換えてください（関数の上に手順コメントあり）。

## 3. テーマカラーを切り替える

`src/site.config.ts` の `theme.preset` を書き換えるだけ。CSS を触る必要はありません。

| プリセット | 雰囲気 | 背景 / 文字 / アクセント |
|---|---|---|
| `'acid'`（既定） | 黒 × 蛍光グリーン。エネルギッシュなクリエイター向け | 白 / 黒 / `#CCFF33` |
| `'editorial'` | 紙のようなオフ白 × 煉瓦色。雑誌・編集の趣味 | `#F4F1EA` / 黒 / `#C8452F` |
| `'mono'` | 完全な白黒。モノクロで締めたいとき | 白 / 黒 / ダークグレー |

アクセントカラーは「ホバー時の下線・カスタムカーソル・セクション番号」などポイントにだけ使われる設計です（画面の 5% 以内）。どのテーマでもうるさくなりません。

## 4. セクションの ON/OFF とページの増減

**セクションを消す・付ける**：`src/site.config.ts` の `sections` で、各セクションの `enabled` を `true` / `false` に。
例：お客様の声（voices）やロゴの壁（clients）が要らなければ `enabled: false`。番号（01/02/…）は自動で振り直されます。

**ナビの並び**：同じく `nav` 配列の順番を入れ替えるだけ。

**ページを増やす**（少しだけ構造の知識が必要）：
1. 既存の `about.html` をコピーして `新ページ.html` を作る。
2. `src/pages/` に対応する TS ファイルを追加（既存ページを参考に）。
3. `vite.config.ts` の `rollupOptions.input` と `server/routes/index.ts` の `pageRedirects` に 1 行ずつ登録。
4. `site.config.ts` の `nav` にページを追加。

## 5. デプロイする

このプロジェクトは `coze` CLI で管理されています。

- **開発**：`coze dev`（プレビュー用ローカルサーバー。ポートは環境変数 `DEPLOY_RUN_PORT` で自動指定）
- **本番ビルド**：`coze build` → `dist/` に静的ファイルが出力されます
- **本番起動**：`coze start`

独自ドメインで公開する場合は、各 HTML の `og:image`（共有時のサムネイル）が相対パスになっている点だけ注意してください。公開 URL が決まったら、`https://あなたのドメイン/placeholder/og-cover_1200x630.svg` のような絶対 URL に書き換えると確実です。

### GitHub Pages で公開する（静的ホスティング）

サーバー機能なしの静的ホスティングにもそのまま出せます。ビルドは相対パス出力（`base: './'`）なので、`<user>.github.io/<repo>/` のようなサブパスでも動きます。

1. `pnpm install` → `pnpm build:static`
2. `dist/` の中身をリポジトリに push する（`docs/` フォルダや `gh-pages` ブランチ、GitHub Actions など任意の方法で）
3. リポジトリの Settings → Pages で公開元を選ぶ

静的ホスティング時の挙動の違い：

- **画像**：プレースホルダーは事前生成済みの静的 SVG（`public/placeholder/`）なので、そのまま表示されます。作品を増減した場合は `pnpm gen:placeholders` を実行してからビルドしてください。
- **お問い合わせフォーム**：API（`/api/contact`）が無い環境では、送信ボタンが自動的に「メール作成画面を開く」動作にフォールバックします（宛先は `site.config.ts` の `brand.email`）。Formspree などのフォームサービスに変えたい場合は `src/lib/interactions.ts` の fetch 先を書き換えてください。
- **URL**：`/works` のようなクリーンパスはサーバー側リダイレクト依存のため、静的ホスティングでは `works.html` への直接リンクになります（テンプレート内のリンクはすべて `.html` 形式に統一済み）。

## 補足：よくある質問

- **言語の切り替え**：ヘッダーの `JA / EN` ボタンで、ボタン文言などの「界面テキスト」が日英で切り替わります（作品タイトルなどの中身は `site.ts` の記述のまま）。選択はブラウザに記憶されます。
- **お問い合わせフォーム**：開発環境では `/api/contact` に送信され、サーバー側でバリデーションと簡易レート制限（同一 IP 10 分に 5 件）を行います。静的ホスティング時はメール作成画面へのフォールバックに自動切替。実際のメール転送を組み込む場合は `server/routes/index.ts` を拡張してください。
- **SNS リンク**：`src/data/site.ts` の `socials` が初期値 `#`（仮リンク）です。自分のアカウント URL に必ず差し替えてください。
- **favicon**：`public/favicon.svg` を差し替えるだけ。
